# TrafficLens

Indian traffic analytics: detect, track and count vehicles (including auto-rickshaws and two-wheelers) in road videos, using a YOLO detector fine-tuned on Indian traffic data. The project measures how much the fine-tuned model improves on a COCO-pretrained baseline.

> 🚧 Work in progress. See [`docs/PLAN.md`](docs/PLAN.md) for the plan, dataset choice and architecture.
